# 区域驾驶舱指标与图表布局设计

## 目标

重构区域驾驶舱的数据层级，让领导能够按照“总体规模 → AI 运行与资产 → 学校及能力排名 → 地图空间分布”的顺序理解区域 AI 教育使用情况。

## 非目标

- 不修改学校驾驶舱。
- 不接入真实后端接口，继续使用当前静态演示数据。
- 不新增图表依赖，沿用 ECharts、HTML、CSS 和原生 JavaScript。
- 不改变学校地图点位、学校看板跳转、时间筛选、全屏和实时 Query 播报功能。

## 页面布局

页面继续使用 1440×900 设计基准并等比适配视口，无全局滚动条。

- 顶部：3 个区域核心指标。
- 左侧：宽 250px 左右，展示一个“AI 运行与资产”复合面板。
- 中间：地图，占据最大可用宽度。
- 右侧：宽 300px 左右，纵向排列 3 个排名面板。

## 顶部核心指标

### 应用学校数

- 定义：学校有任意用户登录校园版，即计为使用学校。
- 展示：学校数量、单位“所”、区域覆盖率。
- 图形：大数字卡片，不增加趋势百分比。

### 赋能老师数

- 定义：登录校园版的去重老师数。
- 展示：老师数量、单位“人”、口径说明。
- 图形：大数字卡片。

### 辅助工作数

- 定义：按对话 ID 去重后的对话数量。
- 展示：对话数量、单位“次”、口径说明。
- 图形：大数字卡片。

## 左侧：AI 运行与资产链路

左侧使用单一复合面板，内部纵向排列五个指标模块，避免五个独立边框挤压空间。

### 执行任务数

- 定义：已完成的 AI 任务总数。
- 组成：课件、资源、题单、应用等。
- 图形：总数 + 四段堆叠条；颜色表示任务类型，悬浮显示分类数量。

### 词元消耗量

- 定义：区域内 AI 对话和任务执行消耗的模型 Token 总量。
- 图形：总数 + 近时间范围微型面积趋势图。

### 对话轮数

- 定义：用户与 AI 完成的一问一答轮次数量。
- 图形：总轮数 + 平均每个对话轮数的迷你环形图。

### 资源沉淀数

- 定义：区域知识库、资源中心、应用中心、题库的资产总量。
- 图形：总数 + 四段环形构成图。

### 资源复用数

- 定义：学情分析、知识库、题库等资产被 AI 调用的总次数。
- 图形：总调用数 + 分段流光条，按调用来源区分颜色。

左侧视觉顺序表达“执行任务 → 消耗与交互 → 沉淀资产 → 资产复用”。

## 右侧：排名

### 学校使用老师数排名

- 图形：棒棒糖排名图。
- 内容：学校名称、去重老师数、名次。
- 默认展示：前 5 名。

### 学校使用对话数排名

- 图形：横向能量条排名。
- 内容：学校名称、按对话 ID 去重的对话数量、名次。
- 默认展示：前 5 名。

### AI 能力使用排名

- 图形：矩形树图。
- 内容：AI 能力名称、使用次数；面积代表次数，颜色区分能力。
- 默认展示：前 6 项。

三块排名均保留左右分页，查看后续数据。分页切换不改变时间筛选。

## 中间地图

- 地图保持页面最大视觉面积。
- 点位大小映射学校赋能老师数。
- 点位光晕强度映射学校辅助工作数。
- hover 展示学校名称、老师数、对话数、任务数。
- 点击进入对应学校驾驶舱。
- 底部保留学校名称、老师名称、用户 Query 的实时播报。

## 时间筛选

时间范围变化时同步更新：

- 顶部 3 个核心指标。
- 左侧 5 个运行与资产指标及其微型图形。
- 右侧 3 个排名的数值和图形比例。
- 地图 hover 数据。

## 动效

- 数字使用短时递增动画。
- 微型趋势、堆叠条、环形图使用一次性入场动画。
- 地图点位保留轻量呼吸效果。
- 排名分页采用淡入切换。
- `prefers-reduced-motion` 下关闭非必要动画。

## 验收标准

- 顶部只出现应用学校数、赋能老师数、辅助工作数三个指标。
- 左侧完整展示执行任务数、词元消耗量、对话轮数、资源沉淀数、资源复用数。
- 右侧完整展示学校使用老师数排名、学校使用对话数排名、AI 能力使用排名。
- 左侧至少使用堆叠条、面积趋势、环形构成三种图形语言。
- 右侧三项分别使用棒棒糖、能量条和矩形树图，不退化成三个相同列表。
- 地图仍是主内容区最大组件。
- 日期筛选、hover、跳转、全屏和实时播报功能无回退。
- 1440×900 及等比缩放视口无全局滚动条、无内容重叠。

# 区域与学校驾驶舱图表多样化设计

## 目标

面向领导参观和对外展示，在不增加业务指标口径的前提下，让区域版和学校版形成不同的视觉叙事：区域版回答“全区域如何使用并产生成果”，学校版回答“AI 如何进入教学并沉淀成果”。科技感作为统一底色，教育成果是视觉焦点。

## 设计原则

- 不为丰富而堆图表，每个组件只回答一个问题。
- 区域版与学校版共享颜色、边框、字体、动效节奏和时间筛选逻辑。
- 取消两版完全同构的图表组合，建立清晰的层级差异。
- 页面保持 1440×900 设计基准自适应，无全局滚动条。
- 数据仍使用当前静态演示数据，不引入新接口或新依赖。

## 区域版：全景地图叙事

### 中心视觉

保留并强化区域地图。地图节点不只表示学校位置，还通过节点尺寸表达活跃老师数，通过节点光晕表达 AI 任务产出强度。悬浮内容维持活跃老师数、对话次数和学校看板入口。

### 左侧

- 高频 AI 能力由单一条形榜升级为“能力矩阵”：保留排名和精确次数，同时用不同长度、亮度与能力标签形成节奏。
- 学校使用老师数保持可比较的横向榜单，作为地图节点的量化补充。

### 右侧

- 学校对话次数使用“贡献星河”：点状排名与迷你轨迹结合，突出学校之间的相对层级。
- 学校生成任务数使用分段能量条，体现任务产出规模，避免与对话榜长得完全相同。

### 成果播报

底部轮播继续展示学校、老师和真实 query，视觉上改为“实时教学成果”播报带，强化事件发生感。

## 学校版：成果故事叙事

### 中心视觉

保留四阶段教学飞轮：使用老师数 → AI 对话次数 → AI 生成任务数 → 内容沉淀数。四张数据卡继续作为唯一核心指标区，通过更明显的色彩分区与环形方向提示表现因果链路。

### 左侧

高频 AI 能力由传统排行榜升级为“能力词云 + 精确榜单”的混合表达。高频能力以字号和颜色强调，次数仍清晰可读，兼顾展示冲击和数据可信度。

### 右侧

- 老师对话次数改为“教师活跃星轨”，通过节点、轨迹和数值表现教师参与。
- 老师生成任务数改为“成果卡片堆栈”，每位老师以任务产出卡展示，形成与对话次数不同的视觉语言。

### 成果播报

飞轮底部保留老师 query 播报，标题和标签改为“本期教学成果”，将对话行为解释为正在发生的教学实践。

## 交互与动效

- 时间筛选继续驱动所有数值变化。
- 图形仅使用轻量 CSS 动效：节点呼吸、轨迹流光、成果卡浮动；避免影响可读性的持续大幅运动。
- 悬浮展示精确数值和口径说明。
- 尊重 `prefers-reduced-motion`，减少非必要动画。

## 验收标准

- 区域版中心仍是地图，但左右四块至少呈现三种不同图形语言。
- 学校版中心仍是飞轮，左、右侧不再全部表现为相同横向进度条。
- 两版在色彩、标题、边框、间距和字体上保持统一。
- 时间筛选、学校跳转、全屏和查询播报功能不回退。
- 1440×900 及等比缩放视口无全局滚动条、无内容重叠。
